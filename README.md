# ISAC-one-gateway.github.io

ISAC Project Homepage

This homepage is simple and small.
For detailed documentation, create a new repository.

## Quarto

The website is created with Quarto (https://quarto.org/).

## Build Website

Just run

```
quarto render
```

To preview locally, run

```
quarto preview
```

## Multilingualisation

No language is main. 
However, for convenience, always keep English qmd as the latest.

Maintain the contents in all the languages.
Please use AI for the languages you are not familiar with.

## Commit and Push

Rendering recreates docs folder. Before you commit, create an empty file (docs/.nojekyll) or run:

```
touch docs/.nojekyll
```
